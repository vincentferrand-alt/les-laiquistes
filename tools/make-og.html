Les laïquistes — images de partage et icônes

Cette page dessine, avec le code du jeu, l'image d'aperçu (WhatsApp, réseaux sociaux) et les icônes de l'appli. Clique sur « Télécharger » puis mets chaque fichier à l'endroit indiqué dans le dépôt GitHub. Ouvre la page depuis le dossier du jeu (http://localhost:8000/tools/make-og.html ou directement le fichier).
